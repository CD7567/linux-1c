# Функциональные требования

Так как это наш проект, требования устанавливаем сами.

## MVP

1. Модуль должен успешно загружаться и выгружаться стандартными средствами работы с kernel modules;
2. Модуль должен создавать каталог /proc/procfs_monitor при инициализации и удалять его вместе со всеми своими узлами при выгрузке;
3. Модуль должен предоставлять файл /proc/procfs_monitor/system для чтения общесистемной статистики;
4. Модуль должен предоставлять PID-ориентированный интерфейс вида /proc/procfs_monitor/pid/<pid>;
5. Чтение /proc/procfs_monitor/system должно возвращать текстовый вывод в стабильном формате kv-пар, пригодном для чтения человеком и для простого парсинга userspace-утилитой;
6. Чтение /proc/procfs_monitor/pid/<pid> должно возвращать информацию о процессе только для указанного PID, найденного на момент обращения;
7. В файле /proc/procfs_monitor/system должны присутствовать как минимум: uptime системы, общая память, доступная память, использованная память и общая загрузка CPU;
8. В файле /proc/procfs_monitor/pid/<pid> должны присутствовать как минимум: pid, ppid, имя процесса, состояние процесса, число потоков, объём памяти процесса и накопленное CPU time;
9. При обращении к несуществующему PID модуль должен корректно завершать запрос с ошибкой уровня “процесс не найден”, а не возвращать фиктивные данные;
10. Для вывода содержимого proc-файлов должен использоваться seq_file или эквивалентный безопасный механизм последовательного чтения.

## Optional

11. В /proc/procfs_monitor/system желательно добавить число процессов в системе и, возможно, разбивку по состояниям running/sleeping/zombie;
12. Для system view желательно считать CPU usage как интервальную метрику по разности двух снимков, а не как разовое абсолютное значение. CPU usage корректно интерпретируется именно как величина на интервале времени;
13. Для process view желательно добавить vm_size и rss как отдельные memory-метрики, а не только один агрегированный показатель;
14. Интерфейс должен быть корректен при параллельном чтении метрик системы и разных PID;
15. Желательно подготовить небольшую user-space утилиту для более красивого отображения статистики.
