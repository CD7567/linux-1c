# Project: procfs system monitor

Согласно изначальным требованиям, условились иметь набор системных метрик и попроцессных метрик.
При этом путь до файла процесса должен разрешаться динамически. Оказалось, что возможность редактирования
lookup операций на директориях в procfs выпилена с некоторой версии ядра (при формировании ТЗ я увидел
устаревшую информацию). Поэтому я принял решения в рамках procfs реализовать on-demand интерфейс создания
procfs файлов. А динамический lookup уже реализовать внутри своей файловой системы monfs.

Модуль протестирован в виртуальной машине на базе Debian:
```shell
wget https://cloud.debian.org/images/cloud/trixie/latest/debian-13-generic-amd64.qcow2
```

Версия ядра `6.12.85+deb13-amd64`.

[Демо работы](DEMO.md)

## Инструкция по запуску

### Сборка

Сборка в релизном режиме:
```shell
make module
```

Сборка в отладочном режиме с дополнительным логированием:
```shell
make module DEBUG=1
```

### Установка в систему

#### Монитор на базе procfs

Установка модуля ядра:
```shell
sudo insmod procfs_monitor.ko
```

#### Монитор на базе monfs

Установка модуля ядра:
```shell
sudo insmod monfs_monitor.ko
```

Создание директории монтирования:
```shell
sudo mkdir -p /mnt/monfs
```

Монтирование monfs:
```shell
sudo mount -t monfs none /mnt/monfs
```

После работы размонтирование monfs:
```shell
sudo umount /mnt/monfs
```
